# Updates: November 24, 2026

The first weekly import from Wikidata brought in far more finds than expected. This update narrows
the import to the Holy Land and keeps unchecked finds off the map unless a visitor asks for them.

## Fewer, closer finds from Wikidata

### What changed

The Weekly data workflow ran for the first time on November 23. It imported 1,192 finds from
Wikidata, most of them museum objects from places far from the Holy Land:

| Place | Finds |
|---|---|
| Heliopolis, Egypt | 419 |
| Susa, Iran | 157 |
| Rome | 89 |
| Thebes, Egypt | 72 |
| Cyprus | 70 |
| Carthage | 69 |

None of them had been checked, and none said what it shows about the Bible. They put gold dots
across Egypt and Mesopotamia. They also made the map's finds file 1.25 MB, which every visitor
downloaded.

The import now looks only at places in and near the Holy Land: Israel, the Palestinian
territories, western Jordan, southern Lebanon and Syria (Tyre, Sidon, Byblos, Damascus), and the
northern Sinai. It also skips items that have no English name in Wikidata.

A test run with the new limit found 61 finds instead of 1,192. They include the Mesha Stele,
which names King Omri of Israel, and an ossuary and an epitaph from Jerusalem.

### Why

Wikidata lists thousands of objects from big museum collections, like the Louvre's and the Museo
Egizio's. Most come from places the Bible names, but they say nothing about the Bible itself. The
map is about the world of the Bible, so finds from far away are better added by hand, one at a
time, with a note saying what each one shows.

### How it works

The area is set in one place, `REGION` in `scripts/import_wikidata_artifacts.py`. Widen it there,
and the next weekly run imports the new area.

When the import finishes, it removes any Wikidata find it no longer returns. So the next run
deletes the far-away finds by itself. Hand-picked finds are never removed.

## Unchecked finds stay off the map

### What changed

The map now shows only finds that a person has checked. The finds card under the map has a new
checkbox, "Also show … finds not yet reviewed". Ticking it adds the Wikidata imports, labeled
"Being checked".

### Why

An imported find hasn't been looked at by anyone on this site. It might be dated wrongly or linked
to the wrong place. Visitors should see checked finds first, and see unchecked ones only when they
choose to.
